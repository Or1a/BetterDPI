# Netify Stats for OpenWrt

本地流量分析 LuCI 页面，当前版本 **0.3.1**，见 [GitHub Release](https://github.com/Or1a/BetterDPI/releases/tag/V0.3.1)。安装包已由 OpenWrt 24.10.8 和 25.12.5 对应官方 SDK 构建，并核对发布附件的内容、权限与校验和；真实路由器安装升级和长期验证仍待完成，范围见 [RELEASE-PREPARATION.md](RELEASE-PREPARATION.md)。项目源码采用 [GPL-3.0-only](LICENSE)，允许商用，但再分发须遵守 GPL 条款。社区分类规则保留各自许可证和来源信息；v2fly/domain-list-community 与 NextDNS/services 均为 MIT，详见 [规则来源与重建](rules/README.md)。

## 数据与统计口径

界面跟随 LuCI 的语言设置：中文（简体/繁体）使用内置翻译，English 使用英文原文。菜单、图表、分页、设置、提示和内置应用名称一起切换；日期遵循 LuCI 页面的语言。用户设备名与实际域名不翻译。切换语言保存后刷新页面即可，无需插件独立设置。翻译源码与编译说明见 [i18n/README.md](i18n/README.md)。

Netify 在路由器 LAN 接口识别连接，通过本地 socket 交给采集器。采集器按小时存储应用、主机名、设备和收发字节；页面通过 rpcd 查询本地汇总。社区域名规则只辅助应用归类，不增加网络探测，不覆盖原始记录；原生识别优先，不确定的多义规则不强行归类。

- 统计仍留在 `/tmp/netify-stats/stats.db`，重启即消失。V0.3.1 新增分层保留：最近 7 天保留小时、设备、应用、协议和域名明细，边界小时也保留；更旧记录分批合并为设备 × 应用 × 协议的上传、下载、逐小时活跃连接数累计，不按天另存。
- 容量设置为 0 时不限；设置 4–4096 MiB 整数时，先回收已不再引用的字典及空闲页，再淘汰旧累计条目，最后淘汰最早小时明细。累计条目按最后包含的小时排序，必须整条删除，无法再按天拆分；保留期限不凌驾于用户设置的容量限制。
- 仅分析开关、容量上限和手动接口绑定保存在 `/etc/netify-stats.json`。关闭分析停止采集并保留历史，重新开启不补算暂停时段的接口流量。
- “接口流量”独立读取用户选定网卡的 RX/TX 计数，不自动绑定 WAN；选择后须“确定保存”，不同接口历史分开。它不与设备排行相加。
- 页面下载在前、上传在后；应用和设备服务端分页；站点明细展示前 5 个但不删除底层记录。
- 已识别的 TCP REDIRECT 连接按原设备归属、校正方向并选取单一方向分支；不解密 VPN。迟到代理映射仍有已知去重边界，见发布准备。

## V0.3.x 维护版变更

- 存储 schema 4 沿用 schema 3 的域名字典表，流量主键只使用时间桶和整数 ID，并为设备查询和域名字典清理建立索引。域名索引使用短哈希缩小索引，但始终核对完整字符串，哈希碰撞不会合并域名。已有数据在事务中迁移，迁移前后逐行摘要和计数必须一致；近期原始域名、应用、字节数不因分类规则改变而改写。schema 3 升级只增加累计表，不重新复制明细。
- 查询先聚合整数 ID，再读取结果需要的域名，单设备查询使用专用索引。重复域名较多时可节省空间；域名几乎全部唯一时，字典及辅助索引会增加空间和写入开销，具体样本见 [维护验证记录](RELEASE-PREPARATION.md)。
- 迟到的代理归属纠正只修改仍存在的统计记录，不会把容量清理已删除的小时重新插入为负数。字典清理和空闲页回收分批进行；单条 SQLite 操作仍可能超过维护时间预算，容量限制仍允许暂时超出。
- “全部”的排行榜、设备详情和识别占比包含累计历史，趋势图只包含仍保留的小时明细，页面分别显示包含的历史上传、下载量；域名搜索不能找回已删除的域名。接口累计单独保存，保持内核接口计数与 DPI 计数分离。有限时间范围不会把无法按时间拆分的累计历史混入其中。
- 归档使用同一事务增加累计值并删除源明细；每批最多处理 256 条 DPI 明细及 256 条接口记录，逐条检查 50 ms 协作预算，无待处理记录时每分钟检查一次。规则按需加载，域名缓存上限 256，完成积压后释放；不在逐流量事件路径分类。单条 SQL 或规则加载不受硬实时预算约束。规则读取失败时保留明细并报错；时间跳变后仍待代理纠正的小时延后归档。
- 连接去重使用精确的临时 SQLite 表和小型页缓存，活跃连接保留快速判断状态。临时状态随采集进程退出而丢弃；路由器上的临时文件通常也占用 RAM。容量设置限制统计数据库及其日志，不是整个插件、Netify 或系统的内存上限。
- 排序项“逐小时活跃连接数”表示每个小时分别去重后相加。同一连接在两个小时内有流量会计为两次，不表示跨整个查询范围的独立连接数。
- “查看接口历史”与采集绑定分别选择，可查看已消失接口或所有有记录接口，不会为查看历史而切换当前采集接口。
- 展开应用可查看实际命中的域名规则与来源，或无法归类的原因。多义规则仍不强行选择应用；最多展示五条规则依据与五个候选，更多结果明确显示为抽样。
- 域名规则扩充至 23,895 条，定向补入 Kimi、Qwen、MiniMax、Mistral、OpenRouter、Ollama 等服务。没有有效域名时，利用已有 Netify 协议信息分为 TLS、QUIC、DNS、HTTP、STUN、P2P、SSH、VPN 或 TCP/UDP 流量，并明确标注“应用未识别”。共享 CDN/托管域名只显示基础设施归属，不据此推断具体应用。
- “流量识别情况”按当前时间及设备筛选展示已识别应用、仅域名或基础设施、仅协议、未识别的字节占比；这是流量构成，不是算法置信度。全部分类使用本地数据，不新增联网查询、主动探测、抓包或后台服务；更新规则可重新分类保留的明细。归档时冻结应用分类 ID；仅域名流量合并为“历史域名流量”，保持“仅域名”识别级别，删除具体域名和证据。历史应用累计不能用后来的域名规则重新分类。
- 同一连接后续元数据缺少域名或只有 TCP/UDP 时，保留此前观测到的域名及更具体协议；清除连接后不把这些信息带到新的连接。缺少 DPI 协议名时只保留已知 IP 协议号对应的 TCP/UDP，不按端口猜测应用。
- 采集诊断复用现有状态快照，显示服务、连接、最近更新、元数据恢复及未归属流量，并给出排查建议。诊断针对整个采集会话，不随设备或应用筛选；没有新流量事件不等于采集故障，应用未识别也不等于字节未计入统计。
- 可按已识别应用、仅域名或基础设施、仅协议、未识别筛选，并搜索应用名称、标识或原始域名；筛选在分页前应用，总量、趋势、设备排行和明细使用同一范围。命中应用名称会纳入该应用的流量；仅命中域名时只统计对应域名记录，不自动纳入同一应用的其他域名。内置应用名称支持英文与简繁显示别名。设备搜索在现有选择列表中按名称、MAC 或 IP 查找，再选择具体设备。
- 展开应用或流量组后可聚焦其设备和趋势，并清除该筛选。接口 RX/TX 属于独立统计，应用或识别筛选时不展示接口面板。搜索延迟合并输入，沿用每 30 秒刷新和单个在途请求，不增加采集进程、主动探测或持久统计表。
- 本轮未加入迟到应用识别的历史回填：已聚合记录可能包含多条连接，安全拆分需要额外的逐连接贡献记录，并与代理纠正、容量回收及连接去重协调；当前仅后续增量使用更新后的原生识别。
- 页面提供手动检查与确认升级：只从本项目 GitHub Release 获取更新信息和匹配系统系列的安装包，校验大小与 SHA-256 后调用系统包管理器。普通打开页面与流量刷新不会联网检查更新，不增加常驻服务。旧版先手动安装包含更新入口的新版本；安装过程短暂停止采集并重启 rpcd，设置和保留统计不由更新器删除，但不保证升级窗口内统计连续。升级方式见仓库根目录的 `INSTALL.md`。
- 设置文件或个别设置值损坏时，历史统计仍可查看，页面显示配置错误；未知开关状态不会被当作已启用。修复设置后刷新即可重新读取。
- 若系统时间回拨，“全部”保留并展示已有的较晚小时；最近时间范围统一排除当前小时之后的记录，并显示时间异常提示，不改写历史时间戳。

V0.3.1 增加分层存储，其余维护功能自 V0.3.0 提供。实际安装升级和路由器长期资源测试仍须分别验证。

本项目不上传统计到 Netify 云端，也不读取其他带宽监控插件的报表。使用示例配置时须保持 `enable_sink=no`；不要整份覆盖已有 Netify 配置。

## 安装准备

`Makefile` 是已在对应 OpenWrt SDK 构建的配方，依赖 Netify、Python 3/SQLite、LuCI 和 rpcd。安装内容以 `packaging/runtime-manifest.json` 核对，包括查询模块和共享生命周期脚本。包不携带默认用户设置，不覆盖已有 `/etc/netify-stats.json`；sysupgrade 保留清单只包含该小配置，不包含统计。

首次安装须自行确认 Netify 的有效 LAN 采集接口、本地 socket 和 JSON 导出配置。参考 `netifyd.conf` 示例，保持本地 socket 路径 `/var/run/netifyd/netifyd.sock`。包不会修改 Netify/OpenClash 配置。共享安装钩子按已保存开关恢复本项目采集器，卸载不删除统计或设置。

**dist 中的 0.2.5-r1 APK 已过期**，不包含本轮修复，不能代表当前源码。它只保留作历史本地测试件，不要用于新安装或发布。
