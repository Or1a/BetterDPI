# V0.4.2 诊断修复记录

2026-11-04。两次用户诊断快照显示采集器连接正常、队列为空，但容量丢弃和缺失元数据计数较高，候选连接全部零分。快照没有全量原始事件，不能证明具体设备是 PCDN，也不能把累计计数换算为漏采字节或包数。诊断附件及设备信息未放入仓库。

## 可复现问题与修复

| 模拟场景 | V0.4.1 | V0.4.2 |
| --- | --- | --- |
| 同设备 32 个小流量端口，再出现上传连接 | 完整组名额预占，上传连接被拒绝 | 33 个身份保留，只有实质上传占完整组 |
| 32 条小连接已经关闭 | 去重保留仍占组名额 | 保留去重水位，释放完整组 |
| 相同 20 对端、相同上传量，分布在 20 个本地端口 | 各组零分，缺少整体观察 | 设备观察分 80，单连接组零分且不封禁 |
| 缺少身份的流量事件 | 全局窗口失效，无法主动恢复 | 从已有导出恢复身份与水位，确定归属后只限制相关组；未知期间保持保护 |
| 排除缓存已满，再收到已知本地流量元数据 | 无关完整连接也受全局限制 | 记录缓存容量事件，不将已知排除流量当作全局缺口 |
| TCP 每 10 秒上传 100、下载 200 字节，持续 6 分钟 | 小时 3600/7200，分钟 2400/7200 | 小时和分钟均 3600/7200；迟到代理纠正仍扣回全部上行 |

恢复只提供身份和累计基线；已排队的旧水位不重复计数，新增量必须连续且新鲜。累计导出字节不进入评分或总账。恢复后及完整组激活后需新的 300 秒窗口。身份不符、未来时间或非法累计值拒绝恢复并保留缺口保护。已知局部缺口不会因数量过多升级为无关组的全局缺口。

完整组上限仍为全局 512、每设备 32、每组 64 条；总身份 2048、样本 16384、队列 512。未成为完整组的身份仅保存短窗口，不能自动处置。恢复请求上限 256、导出读取上限 16 MiB，复用现有维护周期，缓存未变化导出的检查结果。高并发达到上限仍会减少覆盖，低分不代表排除风险。

分钟纠正从每连接 4 条改为全局共享 16384 条，与原最大 4096 × 4 预算相同。只有非零上传占条目；分钟保留、候选到期、清理和纠正均释放。预算不足时标记缺口，避免留下无法撤销的重复上传。旧分钟缺口无法可靠补回。

UI 新增设备观察分、完整／部分覆盖、等待时间和当前用量／上限。累计事件数单独折叠并注明可能重叠，状态过期或有全局缺口时不宣称完整。简繁翻译通过固定 LuCI 工具重新编译；设置、表格及流量页面布局一起改善。

## 开销对照

同一云端 Linux x86_64、Python 3.12.14 环境，使用仓库 `bench_anti_pcdn.py`，对照来自 `V0.4.1`。每组预热后测量 7 轮，下表为中位数。修复版复用每条连接的窗口指标，避免设备和端口视图重复扫描。

| 模拟连接数 | V0.4.1 µs/事件 | 修复后 µs/事件 | V0.4.1 每轮评分 ms | 修复后每轮评分 ms |
| --- | ---: | ---: | ---: | ---: |
| 250 | 64.91 | 46.10 | 10.32 | 5.84 |
| 1000 | 63.25 | 46.79 | 36.50 | 22.10 |

1000 连接的 `tracemalloc` 留存分配从 4,638,198 到 4,721,824 字节（约增加 82 KiB），峰值从 6,504,614 到 6,843,066 字节（约增加 331 KiB）。这是 Python 分配量，不是进程 RSS 或硬上限。

250 连接两版均接受全部 7500 个增量；1000 连接均达到 16384 样本上限，旧版接受 16384 个增量、新版接受 17270 个。新版回收不再持续上传的窗口，故饱和场景的有效覆盖不同，不能视为同等覆盖下的纯吞吐比较。两组均无队列积压。

```sh
python3 netify-stats/bench_anti_pcdn.py 250 --output-dir /tmp/betterdpi-benchmark
python3 netify-stats/bench_anti_pcdn.py 1000 --output-dir /tmp/betterdpi-benchmark
python3 netify-stats/bench_anti_pcdn.py memory --output-dir /tmp/betterdpi-benchmark
```

基准包含 JSON、投影、队列和真实观察／评分代码，使用观察模式与假防火墙，不含数据库写入、socket、线程调度、导出恢复、状态写入或自动处置命令。不能换算为路由器 CPU 占用、线速或真实识别效果。
