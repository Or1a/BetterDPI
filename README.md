# BetterDPI

这里保存 OpenWrt 本地流量分析插件的开发源码，项目说明见 [Netify Stats](netify-stats/README.md)。当前版本为 `0.2.8-dev`，仍在两台路由器上测试。

本仓库是**源码快照，不是正式发布版**：没有提供新的安装包，已知代理连接迟到映射的去重问题尚未修复，SDK 安装/升级流程与长期运行仍待验证。请勿将旧测试包当作当前版本使用。详细待办见 [发布准备](netify-stats/RELEASE-PREPARATION.md)。
